# Used Phone Price

เว็บไซต์ประเมินราคาตั้งขายมือถือมือสองจากข้อมูล ENNXO และ Mac2Hand **9,210 ประกาศ** ราคาแสดงเป็นบาท

**[เปิดเว็บไซต์ Used Phone Price](https://secondhand-phone-price-prediction.streamlit.app/)**

## วิธีใช้งาน

- **ประเมินราคา** — เลือกยี่ห้อ รุ่น และความจุ ระบุวันที่ประกาศ แบตเตอรี่ ประกัน และกล่องเมื่อทราบ แล้วกดประเมินราคา
- **สำรวจข้อมูล** — กรองเว็บไซต์ ยี่ห้อ รุ่น สภาพ และปี ดูกราฟ/ตาราง พร้อมดาวน์โหลด CSV
- **ผลโมเดล** — อ่านวิธีฝึก กราฟ ผลประเมินย้อนหลัง และข้อจำกัด

ใช้กับเครื่องที่ทำงานปกติ ไม่เสียหรือถูกล็อก ข้อมูลเพิ่มเติมที่ไม่ทราบเว้นว่างได้ ผลเป็นการประมาณ **ราคาประกาศ** ไม่ใช่ราคาปิดการขาย ควรเทียบเครื่องรุ่นและสภาพใกล้เคียงก่อนตั้งราคา

## เอกสารโครงการ

| ต้องการอ่าน | เอกสาร |
|---|---|
| เก็บข้อมูล ตรวจ clean และรวม dataset อย่างไร | [ข้อมูล](docs/data.md) |
| โครงสร้างโครงการและหน้าที่ไฟล์แต่ละขั้น | [โครงสร้างและหน้าที่ไฟล์](docs/project.md) |
| สถิติ การกระจายข้อมูล และกราฟสำรวจ | [รายงาน EDA](docs/eda.md) |
| Features การแบ่งข้อมูล การฝึก และผลประเมิน | [รายงานโมเดล](docs/modeling.md) |

EDA สำรวจ 10,032 แถวก่อนคัดคิว 822 แถวออก เหลือชุดฝึก 9,210 แถว โมเดลปัจจุบันใช้ HGB + CatBoost ผลที่รายงานเป็นการประเมินย้อนหลังบนชุดเดิม ยังไม่มีผลทดสอบอิสระของโมเดลที่ฝึกครบ
