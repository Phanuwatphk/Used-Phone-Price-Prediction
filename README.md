# Used Phone Price

เว็บไซต์ประเมินราคาตั้งขายมือถือมือสองจากข้อมูล ENNXO และ Mac2Hand ใช้ฝึก **9,100 ประกาศ** ราคาแสดงเป็นบาท

ป้ายสภาพ `new`/`used` เป็นข้อมูลที่ผู้ขายระบุในตลาดมือสอง ไม่ใช้ยืนยันว่าเป็นสินค้ามือหนึ่ง

**[เปิดเว็บไซต์ Used Phone Price](https://secondhand-phone-price-prediction.streamlit.app/)**

## วิธีใช้งาน

- **ประเมินราคา** — เลือกยี่ห้อ รุ่น ความจุ และสภาพการใช้งาน ระบุแบตเตอรี่และกล่องเมื่อทราบ วันที่เริ่มต้นเป็นวันนี้ แล้วกดประเมินราคา
- **สำรวจข้อมูล** — กรองเว็บไซต์ ยี่ห้อ รุ่น และปี ดูกราฟ/ตาราง พร้อมดาวน์โหลด CSV
- **ผลโมเดล** — อ่านวิธีฝึก กราฟ ผลประเมินย้อนหลัง และข้อจำกัด

ใช้กับเครื่องที่ทำงานปกติ ไม่เสียหรือถูกล็อก ข้อมูลเพิ่มเติมที่ไม่ทราบเว้นว่างได้ ผลเป็นการประมาณ **ราคาประกาศ** ไม่ใช่ราคาปิดการขาย ควรเทียบเครื่องรุ่นและสภาพใกล้เคียงก่อนตั้งราคา

## เอกสารโครงการ

| ต้องการอ่าน | เอกสาร |
|---|---|
| เก็บข้อมูล ตรวจ clean และรวม dataset อย่างไร | [ข้อมูล](docs/data.md) |
| โครงสร้างโครงการและหน้าที่ไฟล์แต่ละขั้น | [โครงสร้างและหน้าที่ไฟล์](docs/project.md) |
| สถิติ การกระจายข้อมูล และกราฟสำรวจ | [รายงาน EDA](docs/eda.md) |
| Features การแบ่งข้อมูล การฝึก และผลประเมิน | [รายงานโมเดล](docs/modeling.md) |
| เอกสารทบทวนสำหรับนำเสนอ | [เอกสารเพิ่มเติม](.local/README.md) |

EDA แยกชุดก่อนคัด 10,032 แถว ชุดฝึกปัจจุบัน 9,100 แถว โมเดล HGB + CatBoost ใช้ validation ตามเวลา 5 ช่วง ช่วงละ 75 วันเท่ากัน และใช้ 13 ฟีเจอร์ ไม่ใช้เว็บไซต์ต้นทางเป็นฟีเจอร์ และไม่รับประเมินเครื่องเสีย/ล็อก ผลที่รายงานเป็นการประเมินย้อนหลังบนชุดเดิม ยังไม่มีผลทดสอบอิสระของโมเดลที่ฝึกครบ

ประวัติโมเดลมี **V1: baseline** และ **V2: โมเดลปรับปรุงที่ใช้ปัจจุบัน** การทดลองฟีเจอร์และสัดส่วน ensemble ทั้งหมดอยู่ภายใต้การพัฒนา V2
