# สรุปโมเดลล่าสุด — รอบ 2

ปรับ feature และเทรนใหม่แล้ว เลือก **HistGradientBoosting + log(price) + น้ำหนักข้อมูลล่าสุด half-life 2 ปี** จาก 12 ตัวเลือก ด้วย validation ตามเวลา 2 ช่วง รวม 1,054 แถว

| เปรียบเทียบย้อนหลังบน 693 แถวเดิม | V1 | V2 |
|---|---:|---:|
| MAE (บาท) | 8,108 | 5,339 |
| RMSE (บาท) | 11,774 | 7,867 |
| R² | 0.147 | 0.619 |

MAE ลด **34.1%**; ENNXO เหลือ 6,090 บาท และ Mac2Hand 3,659 บาท การเปรียบเทียบนี้ใช้ train cutoff เดียวกัน แต่ test เดิมเคยเปิดดูแล้ว จึงเป็นผลย้อนหลัง ไม่ใช่การรับรองด้วย holdout ใหม่

เพิ่มอายุรุ่นจากปีเปิดตัว Apple, tier รุ่น และค่าแบต/ประกัน/กล่องที่ถอดจากรายละเอียดเดิม ค่าที่ไม่ระบุ/ขัดกันคงเป็น missing ไม่แก้ raw หรือชุดหลัก 9,210 แถว และไม่ลบข้อมูลเก่า

**โมเดลใช้งานปัจจุบัน:** `models/asking_price_v2/model.joblib` ฝึกครบ **9,210 แถว / 300 รุ่น** ถึง 2026-10-06 หลังเลือกวิธีแล้ว ไม่มีคะแนน test อิสระของตัวที่ฝึกครบ รุ่น evaluation แยกอยู่ `evaluation.joblib` ใช้ 8,517 แถวสำหรับตารางข้างต้น
