| ประเด็น | ผล |
|---|---|
| ราคาตั้งขาย median | รวม 18,990; ENNXO 8,980; Mac2Hand 19,900 บาท |
| สัดส่วนข้อมูล | Mac2Hand 87.25%; Apple 91.96% |
| ความครอบคลุมรุ่น | 308 คู่ยี่ห้อ–รุ่น; 251 คู่มีน้อยกว่า 10 แถว |
| ราคา IQR ที่ควรตรวจ | 205 จากกลุ่มที่ประเมินได้ 7,543 แถว |
| candidate ข้อความซ้ำ | 280 components / 617 แถว; ยังไม่ยืนยันเครื่องเดียวกัน |
| กลุ่มเทียบสองเว็บได้ | 27 กลุ่ม / 403 แถว คุมรุ่น ความจุ สภาพและปี |

## สถานะก่อนเทรน

ชุดข้อมูลสำหรับโมเดลเลือกแล้ว คิวไม่ต้องติดตามต่อ เหลือแบ่งtrain/validation/testและฝึกbaseline โดยบันทึกวิธีsplitและseed ฟิตpreprocessingจากtrainเท่านั้น และประเมินแยกเว็บ/ช่วงเวลา/รุ่น คะแนนครอบคลุมประชากรหลังคัดตามนโยบายนี้
