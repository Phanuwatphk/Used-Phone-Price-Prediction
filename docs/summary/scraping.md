# สรุปการ scrape ทั้งโครงการ

เก็บประกาศเพื่อพัฒนาโมเดลราคาตั้งขายมือถือ หน้ารวมทั้งสองเว็บครบตาม snapshot รวม 229 หน้าและ 11,601 ประกาศ ไม่ใช่จำนวนประกาศบนเว็บปัจจุบัน ใช้ทุกวันที่ที่เก็บมา

| เว็บ | หน้ารวม | ประกาศ | ผล clean |
|---|---:|---:|---|
| [ENNXO](ennxo.md) | 58 | 1,381 | ผ่าน 1,279 พัก 84 แยกออก 18; ตรวจคิวเดิม 126 ครบแล้ว |
| [Mac2Hand](mac2hand.md) | 171 | 10,220 | ชุดหลัก 8,753; แยกตามปัญหา/ขอบเขต 1,467; คิวเดิม 1,789 มีผลครบ |

รายละเอียด Mac2Hand เก็บรอบทุกวันที่จบแล้ว: สำเร็จ 10,137 ล้มเหลว 83 รายการ เตรียมข้อมูลจาก HTML ที่เก็บไว้แบบ offline ไม่ส่ง request เพิ่ม ตรวจและเก็บ raw เดิมครบทั้งสองเว็บ

ENNXO พักไว้ตามคำขอ Mac2Hand ผ่านกฎ clean และตรวจตัวอย่างประกอบแล้ว คิวเดิมมีผลครบแล้ว มีแถวที่ต้องได้หลักฐานเพิ่มเก็บแยกและกลุ่มที่ต้องตรวจประกาศซ้ำ ตรวจเบื้องต้นแยกเว็บและรวม schema กลางแล้ว 10,032 แถว ทุกแถวมี source ทำ EDA ร่วมแล้ว ยังไม่แบ่ง train/test หรือฝึกโมเดล

เริ่มอ่าน [คู่มือไฟล์](../details/shared/data_guide.md) และ [ชุดข้อมูล Mac2Hand ล่าสุด](../details/mac2hand/finalization.md) เพื่อเลือกผลล่าสุด

อ่าน [ผลตรวจและชุดรวม](../details/shared/combined_dataset.md) รุ่น ราคาและวันเดิมย้อนตรวจได้จาก lineage มีราคาสูงที่ต้องทบทวนต่อก่อนฝึก

อ่าน [สรุป EDA](eda.md) สำหรับสถิติ กราฟและประเด็นที่ต้องตรวจต่อ
