# ชุดข้อมูลที่เลือกสำหรับโมเดลรอบแรก

ผู้ใช้เลือกปิดคิวและตัดสมาชิกคิว EDA ออก เมื่อ 2026-10-11 ใช้ **9,210 แถว** จากชุดรวมเดิม 10,032 แถว

| เว็บ | ใช้ต่อ | ตัดจากชุดรวม |
|---|---:|---:|
| ENNXO | 1,202 | 77 |
| Mac2Hand | 8,008 | 745 |
| รวม | 9,210 | 822 |

ตัดทั้งราคา IQR 205 แถว, สมาชิกกลุ่มข้อความอาจซ้ำ 617 แถว และรายการราคาสูงสุด 10 แถว รวมคิวที่ซ้อนกันแล้ว 822 แถว ไม่เลือกเก็บตัวแทนของกลุ่มซ้ำและไม่ติดตาม review เพิ่ม การตัดเป็นนโยบายผู้ใช้ ไม่ใช่ข้อยืนยันว่าแถวเหล่านั้นผิดจริงทั้งหมด

ใช้ `data/final/dataset.csv` มี source และ schema กลาง 13 คอลัมน์เหมือนเดิม ราคา median หลังเลือก 18,990 บาท สรุปนี้อธิบายชุด 9,210 แถว ส่วน [EDA เดิม](eda.md) สำรวจชุด 10,032 แถวก่อนคัดออก

แบ่งตามวันประกาศแล้ว: train 7,827 / validation 690 / test 693 แถว ฝึกและเปรียบเทียบโมเดลแล้วโดยฟิต preprocessing เฉพาะข้อมูลฝึก คะแนนอธิบายชุดที่เลือกนี้ อ่าน [ผลโมเดล](modeling.md)

อ่าน [วิธีทำ สคริปต์ และทุกไฟล์](../details/shared/model_input.md) หรือเลือก path จาก [registry](../../data/datasets.json)
