# ใช้งานฟอร์มประเมินราคา

เปิดจากรากโปรเจค:

```bash
.venv/bin/python script/app/run_app.py
```

เข้า **http://localhost:8501** เลือกยี่ห้อและรุ่น กรอกความจุและสภาพ แล้วกด **ประเมินราคา** ข้อมูลแบตเตอรี่ ประกัน และกล่องไม่ทราบให้เว้นว่างได้ เปลี่ยนเว็บอ้างอิงและวันที่ในข้อมูลเพิ่มเติม

แอปอ่านโมเดลที่เทรนแล้วใน `models/asking_price_v2/` ผลแสดงบนหน้าจอ ไม่บันทึกทับ dataset ราคาคือราคาตั้งขายโดยประมาณ ไม่ใช่ราคาปิดการขาย ใช้กับเครื่องปกติ ไม่เสีย/ล็อก

แอปรันในเครื่องที่เปิดคำสั่ง กด `Ctrl+C` เพื่อหยุด โมเดล binary ไม่อยู่ใน Git หลัง clone ต้องคืนไฟล์โมเดลหรือเทรนก่อนเปิด

ตรวจแล้ว: tests ทั้งโครงการ **145 ข้อผ่าน** รวมฟอร์ม 5 ข้อ; ฟอร์มทำนายกับโมเดลจริงได้; เปิดจาก directory อื่นได้ และเซิร์ฟเวอร์ตอบกลับ HTTP 200
