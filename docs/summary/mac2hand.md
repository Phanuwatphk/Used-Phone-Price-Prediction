# สรุป Mac2Hand

เก็บครบ 171 หน้ารวม **10,220 ประกาศ** ทุกวันที่ใน snapshot รายละเอียดสำเร็จ 10,137 อ่านไม่ได้ 83 รอบเก็บจบแล้ว ตรวจจากไฟล์ที่เก็บไว้โดยไม่ส่ง request เพิ่ม

**ใช้ dataset.csv (`data/final/mac2hand/mac2hand_20261006T172805_252838_Asia-Bangkok/dataset.csv`) จำนวน 8,753 แถว** สำหรับ EDA ของกลุ่มปกติ ผลล่าสุดอยู่ใน `final/` ส่วน `clean/` และ `manual_review/` เก็บเป็นประวัติ

|---|---:|
| ผ่าน | 8,753 |
| เครื่องเสีย/ล็อก/เก็บศึกษาแยก | 144 |

คิวเดิม **1,789 แถวมีผลและงานถัดไปครบ** ผ่าน 567 แถว ที่เหลือเก็บแยกพร้อมเหตุผล ตรวจซ้ำทั้งชุดพบ 136 แถวที่เคยผ่านแต่ยังมีปัญหา จึงแยกออกด้วย ไม่เติมข้อมูลที่ไม่มีหลักฐาน ไม่อ้างว่า manual ทุกแถว

- รายงานผล (`data/final/mac2hand/mac2hand_20261006T172805_252838_Asia-Bangkok/report.md`) · หลักฐานละเอียด (`data/intermediate/mac2hand/mac2hand_20261006T172805_252838_Asia-Bangkok/finalization/queue_decisions.json`)
- [วิธีทำ สคริปต์ และความหมายของทุกไฟล์](../details/mac2hand/finalization.md)

ผ่าน 102 tests ตรวจ raw/input ไม่เปลี่ยนและบัญชีครบ ชุด Mac2Hand ต้นทางไม่เปลี่ยน; รวมกับ ENNXO แล้วใน [ขั้นรวม](../details/shared/combined_dataset.md) ทำ [EDA ร่วม](eda.md) แล้ว ยังไม่ฝึกโมเดล มีกลุ่มประกาศอาจซ้ำ 185 กลุ่ม 394 แถวเก็บไว้ตรวจและจัดกลุ่มก่อนแบ่งข้อมูล

นโยบายคิวล่าสุด (2026-10-11): ผู้ใช้เลือกไม่ดำเนินการต่อกับแถวที่ไม่ผ่านชุด clean จึงไม่ใช้กับโมเดลรอบแรกและไม่ติดตามหลักฐานเพิ่ม เก็บไฟล์เดิมเป็นประวัติ จำนวนชุดผ่านไม่เปลี่ยน การเลือกแถวจาก flags ของ EDA เป็นนโยบายแยกในขั้นเตรียมข้อมูลฝึก

การเลือกจากEDAเสร็จแล้ว: ชุดโมเดลรอบแรกใช้ENNXO1,202และMac2Hand8,008แถว รวม9,210 แยกจากชุดผ่านเฉพาะเว็บเดิม อ่าน [ชุดโมเดล](model_input.md)
