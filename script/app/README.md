# ฟอร์มประเมินราคามือถือ

เปิดจากรากโปรเจค โดยใช้ environment ที่ติดตั้ง `requirements-lock.txt` แล้ว:

```bash
.venv/bin/python script/app/run_app.py
```

เข้า **http://localhost:8501** เลือกยี่ห้อ รุ่น ความจุ และสภาพ แล้วกด **ประเมินราคา** ช่องแบตเตอรี่ ประกัน และกล่องไม่ทราบให้เว้นว่างได้ ค่าเริ่มต้นอ้างอิง Mac2Hand และวันที่ปัจจุบัน เปลี่ยนได้ในข้อมูลเพิ่มเติม ผลเป็นราคาตั้งประกาศโดยประมาณ ไม่ใช่ราคาปิดการขาย

แอปรันในเครื่องที่เปิดคำสั่งนี้ กด `Ctrl+C` เพื่อหยุด ถ้าพอร์ตถูกใช้ ให้เพิ่ม `--port 8502` หากไม่ต้องการเปิดเบราว์เซอร์อัตโนมัติ ใช้ `--headless` รองรับรันไฟล์ผ่าน absolute path จาก directory อื่น

## ไฟล์และการทำงาน

| ไฟล์ | หน้าที่ / เก็บอะไร |
|---|---|
| `run_app.py` | เปิดเซิร์ฟเวอร์เฉพาะเครื่องนี้ ใช้ Python ตัวเดียวกับที่รันคำสั่ง |
| `price_app.py` | ฟอร์มภาษาไทย เลือกรุ่นตามยี่ห้อ ตรวจข้อมูล และแสดงราคา/ข้อจำกัด |
| `../modeling/predict.py` | ตรวจ checksum โมเดล เตรียม features และทำนาย ใช้ร่วมกับ CLI |
| `../../models/asking_price_v2/model.joblib` | โมเดลใช้งานที่ฝึกครบ 9,210 แถว (อยู่ในเครื่อง ไม่อยู่ใน Git) |
| `../../models/asking_price_v2/metadata.json` | เวอร์ชันและ checksum ที่ใช้ตรวจโมเดลก่อนโหลด |
| `../tests/test_app.py` | ตรวจฟอร์ม การเปลี่ยนยี่ห้อ ข้อมูลไม่ทราบ และกรณีไม่มีโมเดล ด้วย fixture ไม่ใช้ข้อมูลส่วนตัว |

อ่านรายการยี่ห้อและรุ่นจากโมเดล ไม่ scrape หรือเทรนระหว่างใช้งาน ไม่เขียนข้อมูลเครื่องหรือผลทำนายลง dataset ผลแสดงบนหน้าจอเท่านั้น โมเดลถูก cache และโหลดใหม่เมื่อไฟล์โมเดลหรือ metadata เปลี่ยน

## หลัง clone / สำหรับผู้ดูแล

โมเดล binary ไม่ได้ขึ้น Git จึงต้องคืน `model.joblib` และ `metadata.json` จากสำเนาที่เชื่อถือได้ หรือสร้างตาม [คู่มือโมเดล](../modeling/README.md) ก่อนเปิดแอป อย่าเปิดไฟล์ joblib จากแหล่งที่ไม่เชื่อถือ

ทดสอบฟอร์ม: `.venv/bin/python -m unittest script.tests.test_app`

สำหรับทดสอบหรือเลือกโมเดลชุดอื่น กำหนด `PHONE_PRICE_MODEL_PATH` ให้ชี้ไฟล์ joblib ที่มี metadata คู่กัน Path แบบ relative อิงรากโปรเจค ไม่อิง directory ที่เปิดคำสั่ง

หน้าจอใช้ [Streamlit](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest) และทดสอบด้วย AppTest ผลประเมิน/ข้อจำกัดโมเดลอ่านที่ [สรุปโมเดล](../../docs/summary/modeling.md)
