# แนวตอบสำหรับนำเสนอ

เอกสาร Model Version 2 อ่านคู่กับ [ผลโมเดล](../docs/modeling.md) และ [EDA](../docs/eda.md) โครงการมี V1 เป็น baseline และ V2 เป็นโมเดลใช้งานปัจจุบัน การทดลองภายใน V2 ไม่นับเป็นเวอร์ชันใหม่ ตัวเลขด้านล่างเป็นการประเมินย้อนหลัง ไม่ใช่คะแนนทดสอบอิสระของโมเดลใช้งาน

## ประโยคอธิบายงาน

“งานนี้ช่วยเสนอราคาตั้งขายมือถือมือสองที่ใช้งานปกติ จากประกาศ ENNXO และ Mac2Hand โดยใช้รุ่น ความจุ วันประกาศ และข้อมูลแบตเตอรี่/กล่องที่ทราบ ผลเป็นราคาอ้างอิงสำหรับเริ่มตั้งขาย ไม่ใช่ราคาที่รับรองว่าจะขายออกได้”

## เหตุผลของฟีเจอร์

กำหนดจากข้อมูลที่มีในเวลาตั้งประกาศและผู้ใช้กรอกได้ หรือคำนวณให้ได้ ไม่ใช้ราคาเป้าหมาย รหัส URL หรือข้อความที่อาจมีราคาเป็น input โมเดลปัจจุบันมี 13 ฟีเจอร์:

| ฟีเจอร์ | เหตุผลและข้อจำกัด |
|---|---|
| `brand`, `model` | ระบุสินค้าที่กำลังประเมิน ต่างรุ่นมีสเปกและระดับราคาต่างกัน |
| `model_family` | รูปแบบชื่อรุ่นที่แทนเลขด้วย # ช่วยแชร์ข้อมูลระหว่างรุ่นชื่อคล้ายกัน ไม่ใช่การยืนยันว่าใช้ฮาร์ดแวร์ตระกูลเดียวกัน |
| `device_tier` | คำในชื่อ เช่น Pro/Plus/Ultra เป็นหมวดหมู่ ไม่กำหนดให้มีลำดับราคาตายตัว |
| `storage_gb` | ความจุเป็นคุณสมบัติเครื่องที่ทราบก่อนตั้งราคา |
| `publication_days` | วันที่ตั้งประกาศนับจากวันอ้างอิง ใช้บอกช่วงเวลาของราคา ไม่ใช่อายุเครื่อง |
| `release_year` | ปีเปิดตัวจาก catalog สำหรับ iPhone ไม่เดาปีให้ Android ที่ไม่มีข้อมูลอ้างอิง |
| `model_age_years` | อายุของรุ่น ณ เดือนประกาศโดยประมาณ ช่วยแยกวงจรรุ่นออกจากช่วงเวลาตลาด ไม่ใช่เวลาที่เจ้าของใช้เครื่องจริง |
| `release_known` | แยกกรณีที่มี/ไม่มีข้อมูลปีเปิดตัว |
| `battery_health_pct`, `battery_missing` | ใช้ค่าแบตเตอรี่ที่ระบุชัด พร้อมแยกไม่ทราบ ไม่ใช้ “สภาพ 99%” เป็นแบตเตอรี่ 99% |
| `box_mentioned`, `box_missing` | ใช้คำกล่าวว่ามี/ไม่มีกล่อง และแยกไม่ทราบ ไม่รับรองว่าเป็นกล่องเดิมของเครื่อง |

ฟีเจอร์อายุรุ่น/family/tier แม้คำนวณจากข้อมูลเดิม แต่ทำให้ความหมายที่ต้องการแชร์ระหว่างรุ่นปรากฏชัด ต่างจากการใส่ตัวแทนชื่อเดียวกันซ้ำ ๆ ไม่อ้างว่าฟีเจอร์เหล่านี้ทำให้ราคาเปลี่ยนเชิงเหตุและผล

| สิ่งที่ไม่ใช้ | เหตุผล |
|---|---|
| `source` | ผู้ใช้ต้องการราคาอ้างอิงทั่วไปและยังไม่ได้เลือกเว็บที่จะขาย เว็บไซต์ไม่ใช่คุณสมบัติเครื่อง เก็บไว้ตรวจที่มาและผลแยกกลุ่ม |
| `condition` เป็นฟีเจอร์ | เป็นค่าคงที่ในชุดฝึกปัจจุบัน จึงไม่ใช้เป็นฟีเจอร์ ป้ายนี้ไม่ยืนยันมือหนึ่ง/มือสอง |
| `brand_model` | ประกอบจาก brand/model ที่เก็บอยู่แล้ว |
| `log_storage` | แปลงจากความจุเดิม ซึ่งโมเดลต้นไม้แบ่งช่วงจาก storage ได้อยู่แล้ว |
| `model_number` | เลขที่ดึงจากชื่อไม่มีหน่วยหรือความหมายร่วมกันระหว่าง Galaxy A, Galaxy S และ iPhone |
| `publication_year`, `publication_month` | มีข้อมูลปฏิทินอยู่ในวันที่แล้ว เลือกใช้ตัวแทนหลักเพื่อลดการใส่ข้อมูลซ้ำ |
| ประกันและตัวบ่งชี้ที่ขาด | ชุดฝึกปัจจุบันมีค่าชัดเจนเพียง 157/9,100 แถว (1.73%) รอบนี้เลือกแบบระมัดระวัง ไม่ให้ผู้ใช้กรอกตัวแปรที่หลักฐานเบาบาง มีตัวทดลองใช้ประกันไว้เปรียบเทียบ ไม่สรุปว่าประกันไม่มีผลต่อราคาจริง |
| เกรดรอยตำหนิ/ประวัติซ่อม | ยังไม่มีคอลัมน์ที่ผ่านการตรวจพร้อมฝึก ไม่สร้างคะแนนหรือสูตรหักราคาเอง |
| อายุเครื่องจริง | ไม่มีวันซื้อหรือเริ่มใช้งานที่เชื่อถือได้ จึงไม่ใช้ปีเปิดตัวแทน |

## วิธีฝึกและผลประเมิน

กำหนดขอบเขตและชุดฟีเจอร์ก่อน scoring จากนั้นเทียบสัดส่วน CatBoost 25%, 50%, 75% กับ HGB ที่เหลือ บน forward validation 2 ช่วง รวม 955 ประกาศมือสอง เลือก 50/50 ด้วย MAE **3,698.34 บาท** ตัวเปรียบเทียบ V1/โมเดลมี source/โมเดลมีประกันเป็นข้อมูลประกอบ ไม่แข่งเป็นโมเดลใช้งานนอกชุดฟีเจอร์ที่กำหนด

ทั้งสองโมเดลเรียนรู้ log ราคา แล้วแปลงกลับเป็นบาทก่อนเฉลี่ยราคา 50/50 ให้น้ำหนักข้อมูลใหม่มากขึ้นด้วย half-life 2 ปี โดยไม่ลบประกาศเก่า น้ำหนักและ preprocessing เรียนรู้จากข้อมูล train ของแต่ละ fold เท่านั้น

| ตัววัดย้อนหลังบนมือสอง 682 ประกาศ | ค่า |
|---|---:|
| MAE | 3,597.24 บาท |
| Median absolute error | 2,090.00 บาท |
| RMSE | 6,038.96 บาท |
| R² | 0.7738 |
| อยู่ภายใน ±20% ของราคาประกาศจริง | 59.09% |
| Bias | −2,032.20 บาท |

เปรียบเทียบ V1 reference และ V2 บน **มือสอง 682 แถวเดียวกัน** ตามตารางในรายงานโมเดล โดยฝึกวิธี baseline ใหม่ด้วยขอบเขตและ cutoff เดียวกัน ไม่ใช้คะแนนจากชุดประเมินเก่าที่มีจำนวนแถวต่างกันมาเทียบตรง ๆ

iPhone มี MAE 2,623.01 บาทจาก 432 แถว ส่วน Android มี MAE 5,445.43 บาทจาก 239 แถว กลุ่มที่ยังไม่ยืนยัน OS มี 11 แถว ข้อมูลฝึกส่วนใหญ่เป็น iPhone และ catalog ปีเปิดตัวมีเฉพาะ iPhone จึงยังไม่ควรรับรองผล Android เท่ากัน

## แนวตอบคำถาม

**ทำไมใช้ราคาประกาศ ไม่ใช้ราคาขายจริง?** เก็บได้จากประกาศสาธารณะ แต่ไม่มีหลักฐานราคาปิดขาย จึงตั้งเป้าหมายเป็นราคาตั้งประกาศ และไม่อ้างว่าเป็นราคาที่ขายออกแน่นอน

**ทำไมไม่ให้กรอกสภาพเครื่องละเอียด?** `condition` มีทุกแถวแต่บอกแค่ new/used ไม่ใช่ระดับรอยหรือผลตรวจ การเพิ่มช่องโดยไม่มีข้อมูลฝึกจะทำให้ผู้ใช้เข้าใจว่าโมเดลคำนวณสิ่งที่ยังทำไม่ได้ จึงถามสภาพการใช้งานเพื่อตรวจขอบเขต และไม่แสดงราคาเมื่อเลือกเสีย/ล็อก

**ข้อมูลแบตเตอรี่ไม่ครบ ใช้ได้หรือ?** ใช้เป็นข้อมูลเสริมได้ ชุดฝึกปัจจุบันมีค่า 2,898 แถว และมีข้อมูลกล่อง 5,391 แถว แยกไม่ทราบด้วย missing indicators ฝั่ง HGB เติมค่าจาก train เท่านั้น ฝั่ง CatBoost รับ numeric missing ได้ ไม่ถือว่าค่าว่างเป็นศูนย์ และไม่อ้างว่าการกรอกข้อมูลเพิ่มทำให้แม่นขึ้นทุกกรณี

**ถอด source แล้วไม่มีอคติหรือ?** ยังมี ข้อมูลยังไม่สมดุล รุ่น/ปี/ผู้ขายและรูปแบบการขาดข้อมูลต่างกัน การถอด source ทำให้ input ตรงกับโจทย์ แต่ไม่ได้รับประกันว่าโมเดลไม่เรียนรู้ตัวแทนของเว็บผ่านตัวแปรอื่น

**R² 0.7738 คือแม่น 77.38% หรือ?** ไม่ใช่ R² เทียบความคลาดเคลื่อนกำลังสองกับการทำนายด้วยค่าเฉลี่ยในชุดประเมิน ถ้าต้องการสัดส่วนคำทำนายใกล้ราคาจริง งานนี้รายงานภายใน ±20% เท่ากับ 59.09%

**MAE 3,597 บาทแปลว่าทุกเครื่องผิดไม่เกินเท่านี้หรือ?** ไม่ใช่ เป็นค่าเฉลี่ย บางเครื่องคลาดเคลื่อนมากกว่า และไม่ได้ใช้เป็นช่วงความเชื่อมั่น รอบนี้ยังไม่แสดงช่วงราคาที่อ้างระดับความครอบคลุมทางสถิติ

**ทำไมใช้ข้อมูลเก่าและแบ่งตามเวลา?** ราคามือถือสัมพันธ์กับช่วงเวลาและวงจรรุ่น ใช้ข้อมูลเก่าเพื่อเรียนรู้หลายรุ่น พร้อมลดน้ำหนักตามความเก่า และประเมินด้วยการฝึกอดีตทำนายช่วงถัดไป การสุ่มแบ่งอาจทำให้ประเมินง่ายกว่าการใช้งานจริง แต่โมเดลต้นไม้ยังไม่รับประกันการทำนายราคานอกช่วงเวลาฝึก

**ผลนี้ทดสอบอิสระหรือมีนัยสำคัญหรือ?** ยังไม่ใช่ ชุดย้อนหลังเคยถูกเปิดดูระหว่างพัฒนา และการคัดคิว EDA เกิดก่อน split จึงมี selection bias ไม่ได้ทำ hypothesis test จึงไม่อ้างนัยสำคัญทางสถิติ ต้องเก็บช่วงเวลาใหม่ที่ไม่เคยใช้พัฒนาเพื่อทดสอบอิสระ

**ป้าย new หมายถึงมือหนึ่งหรือ?** ไม่ใช่ เป็นป้ายสภาพที่ผู้ขายระบุในตลาดมือสอง ไม่ใช่การยืนยันประวัติการครอบครองเครื่อง

1. เลือก Apple / iPhone 13 / 128 GB เลือกใช้งานปกติ กรอกแบตเตอรี่หรือกล่องเฉพาะที่ทราบ แล้วประเมิน
